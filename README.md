# 🎧 Spotify Web Player — Frontend Clone

A pixel-inspired, front-end clone of the **Spotify Web Player**, built with pure **HTML5 & CSS3**. This project recreates the sleek, dark-themed music streaming interface — complete with a sidebar library, browsable playlist/artist cards, and a fixed bottom music player bar.

> 🎯 Built as a front-end practice project focused on layout, Flexbox, and UI fidelity to a real-world product.

## ✨ Features

- 🎨 **Authentic Spotify UI** — dark theme, rounded cards, and the signature green accent (`#11ee95`)
- 📚 **Sidebar Library** — pinned "Liked Songs" playlist plus a scrollable list of artist cards
- 🔍 **Search Bar** — styled search input with icon and folder-view toggle
- 🎵 **Content Carousels** — multiple horizontally-organized sections showcasing songs, playlists, and stations
- 🎚️ **Music Player Bar** — album art, track/artist name, play/pause/skip controls, progress bar, and volume slider
- 📱 **Responsive Layout** — built with Flexbox for a fluid, app-like structure
- 🔤 **Custom Typography** — Google Fonts (`Montserrat`) for clean, modern text
- 🎯 **Font Awesome Icons** — used throughout for navigation, playback, and UI controls

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure & semantic markup |
| **CSS3 (Flexbox)** | Layout, styling, and responsiveness |
| **Bootstrap** | for quick build some sections of this clone like search bar |
| **[Font Awesome 7](https://fontawesome.com/)** | Icon library (via CDN) |
| **[Google Fonts](https://fonts.google.com/) — Montserrat** | Typography |


## 📁 Project Structure

```
Frontend-Project/
├── index.html          # Main markup — topbar, sidebar, content, player bar
├── style.css            # All styling (layout, theme, components)
├── logo.png              # Favicon / Spotify logo
├── player_icon*.png      # Playback control icons
├── card*img.*             # Playlist / album cover art
├── music*.jpeg|webp        # Track thumbnail images
├── artist*.webp|jpeg        # Artist thumbnail images
└── en-GB*.jpeg                # Station / recommendation cover art
```

## 🚀 Getting Started

No build tools or dependencies required — it's plain HTML & CSS.

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/Frontend-Project-.git
   cd Frontend-Project-
   ```

2. **Open it in your browser**
   ```bash
   open index.html      # macOS
   start index.html     # Windows
   ```
   Or simply double-click `index.html`.
